## 🎯 Featured Projects

### 🤖 [[Autonomous Robotic Sailboat (ARSEM)](https://github.com/SailBoat-Plaksha/)
> Wind-propelled autonomous sailboat for low-cost ocean environmental monitoring

- Built master-daughter board communication protocol (I2C/UART) with fail-safe state machine
- Implemented long-range RC telemetry (2.4 GHz) for manual override
- Designed A* pathfinding algorithm with inverse kinematics for sail/rudder control
- **Tech:** C/C++, Raspberry Pi, GPS, IMU, LoRa, custom PCB design

### 🎮 [Hand-Tracking Suika Game](https://github.com/Armaan-Raisinghani/plakshapangpang)
> Physics-based puzzle game controlled entirely via hand gestures

- Integrated MediaPipe hand tracking with Godot game engine via WebSocket bridge
- Achieved 30 FPS performance with sub-100ms input latency
- **Tech:** Python (MediaPipe, OpenCV), Godot Engine, WebSockets
